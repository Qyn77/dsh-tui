# Bundled dependency notice fallback

`@alcalzone/ansi-tokenize@0.1.3` declares `MIT` in its installed package manifest,
but its npm package omits a license file. The adjacent notice is copied verbatim
from the project's official [upstream LICENSE](https://github.com/AlCalzone/ansi-tokenize/blob/master/LICENSE),
verified on 2026-11-10. This is the upstream notice current at verification time,
not a file extracted from the 0.1.3 tarball; `v0.1.3` and `0.1.3` license URLs
were unavailable.

The build fallback only applies to that exact package name, version and MIT
declaration. A dependency update must review this fallback. All other bundled
package notices are read from their actual installed package directories.
