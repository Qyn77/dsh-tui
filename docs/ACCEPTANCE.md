# rc.5 功能验收

本次在 `codex/dsh-base-0.2.1-rc.5` 实现已批准的功能方向。三种欢迎区保留；更大幅度的配色、边框和排版重设计按“先保功能”的决定暂缓。本文是验收入口，长期状态仍以 [SPEC.md](SPEC.md) Part 2 为准。

## 启动

退出旧进程，再执行：

```sh
dsh --profile tui-rc5
```

本机这个 profile 安装的是本分支打包的版本。只需体验时不用重新构建。开发修改源码后则必须 `pnpm run build`、重新安装包并重启；旧进程不会自动加载新 bundle。`/language zh` 可切换中文。

## 明日人工体验

在 macOS Terminal.app 和 VS Code 集成终端各完成一遍，建议从 120×31 左右开始，再缩窄/缩矮。

| 检查 | 操作与预期 |
| --- | --- |
| 全宽布局 | 发送中英短消息、多行文本；输入 `/`，过滤并移动选择。消息框填满内容列，菜单与输入框边缘对齐，选中背景填满行，无旧边框残留。 |
| 欢迎区 | 新会话下分别调整为宽、窄、矮窗口；三种品牌布局均保留，输入框可见。 |
| 内容滚动 | 请求超过两屏的回复。用触控板、滚轮、PageUp/PageDown 浏览，顶部状态栏和底部输入框固定，中间内容可从头看到尾。浏览时新输出不强制拉回底部。 |
| 鼠标与选字 | Terminal.app 的 `/mouse auto` 默认启用上报；必要时开启其配置中的 Allow Mouse Reporting。F2 或 `/mouse off` 恢复原生选字；`/mouse on` 恢复上报。VS Code 也对比这两种模式。 |
| 过程与时间 | 请求含工具调用的任务；执行时过程可见，结束后保留最终结果和耗时。开启上报后点击摘要，或 `/activity 1` 独立切换；`all`/`none` 控制全部。重启接续后耗时仍在。 |
| 搜索与定位 | `/search 关键词` 获取编号，`/jump N` 定位，`/jump next`/`prev` 遍历匹配，`/jump user`/`tool`/`error` 查看前一条对应内容。 |
| 完整查看与复制 | `/inspect N` 查看完整条目，滚动后 Esc 返回；`/copy N` 复制指定内容。实际粘贴确认剪贴板，OSC 52 发送没有回执。 |
| 会话选择 | 输入 `/sessions ` 或 `/resume `（保留空格），按标题、目录、编号过滤，Enter 接续；切换后旧会话的查看选择不会串到新会话。 |
| 文件修改 | 在临时项目里让模型修改文件；有可用参数和 presenter 时审批卡显示拟议 diff；执行后 `/diff` 或 `/diff N` 查看记录的修改。 |
| 图片草稿 | 拖入图片路径，提交前显示名称、数量、大小；Ctrl-X 移除光标所在图片，否则移除最后一张，其他文本保留。 |
| 恢复 | 中断一个请求，`/retry` 查看结束原因和已成功工具，`/retry draft` 恢复请求文本；`/retry continue` 明确请求模型基于现有结果继续。 |
| 导出 | `/export ./review.md` 导出完整会话，`--entry=N` 导出单条；确认隐藏/收起内容仍可导出，已有文件不会被覆盖。 |
| 分支 | 空闲时 `/branch 1` 从结束的第 1 轮建立新会话；原会话仍可接续，新会话继承记录和耗时。工作文件不会恢复到过去状态。 |
| 收尾 | 浏览历史、打开菜单、切换会话后多次缩放，再打开 `/help`；提示框、帮助开头和滚动应正常。`/exit` 返回 shell 后选字、粘贴、换行正常。 |

## 证据边界

PTY/VT 验收不等于 Terminal.app/VS Code 的原生触控板和真实颜色验收，Windows Terminal 本轮也未实测。

diff 依赖运行时提供的元数据；缺少旧内容时明确标记不可用。审批前无法获取参数时显示原有参数/原因卡，不能保证每个第三方工具都有 diff。

恢复是新一次明确的继续请求，不是运行时事务回滚，也不会直接重放工具；模型后续决策仍按正常权限/审批执行。分支只继承对话，不回滚文件或外部操作。

诊断在 Ink 挂载后写入 `DSH_HOME/tui.log`；警告/错误进入消息区。挂载前的 launcher 或插件输出不属于这条路由。
